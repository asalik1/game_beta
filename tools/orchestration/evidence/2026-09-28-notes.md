## Parallel lanes (the key throughput trick)
- Full checkout of this repo is ~15 GB (art_src 4 GB, game/assets 2.5 GB, mobile 2.5 GB) → a normal
  worktree per agent is too heavy. SPARSE lane worktree = everything but art_src/mobile/game/assets/
  marketing/archive/docs/build (~170 MB, 26 s), plus JUNCTIONS game/assets + game/.godot → main and
  HARDLINKED Godot exes. Compile gate runs in a lane in ~35 s (311 scripts). Script: tools/lane.sh.
- TRAP: sparse worktree + junction made `git status` take 93 s (git checks skip-worktree files that are
  present on disk). `git config sparse.expectFilesOutsideOfPatterns true` → 0 s.
- DANGER: never `git clean` in a lane — junctions point into the main worktree's assets.

## INCIDENT 09:14 UTC — all 20,267 main game/assets files deleted through a lane junction
- Trigger: `git reset --hard` in lane a (my lane.sh reset). Lane a was the first lane, built by hand: I ran
  `git status` there (the 93 s one) BEFORE setting `sparse.expectFilesOutsideOfPatterns=true`. That status
  saw the junctioned files "present despite skipped" and CLEARED their skip-worktree bits. The later
  reset re-applied the sparse patterns → git deleted every "tracked file outside the patterns" → through
  the junction = the MAIN worktree's assets, then removed the (now empty) junction dir. Lanes b-g were

- Detection: T08's implementer reported "missing road_caravan_cart.png" in its report; root then saw
  `D game/assets/...` ×20267 in main's status. Always scan implementer reports for "missing asset".
- Recovery: `git restore --source=HEAD --worktree -- game/assets` (161 s) → then the 10,091 .import files
  came back CRLF (autocrlf=true) and showed as M; `git -c core.autocrlf=false checkout --pathspec-from-file`
  restored LF bytes (91 s) → main clean. The 46 preserved files verified byte-identical (sept26 manifest).
- Fix: `tools/farm.py <lane>` replaces the asset JUNCTION with a per-file HARDLINK FARM (38 s/lane, run
  under glock). A delete in a lane now only removes the lane's links. Junctions were the wrong primitive:
  never share a TRACKED directory by junction with a sparse git worktree.
- 09:50 LOCK STARVATION: 9 waiters queued; glock waiters polled every 5 s with no fairness → my farm job
  waited 20+ min. glock now has a FIFO ticket queue (%TEMP%/crownless_glock_queue) + `--priority` for
  integration/maintenance jobs. Also caught MY OWN `-- cmd.exe /d /c "..."` farm command mangled into
