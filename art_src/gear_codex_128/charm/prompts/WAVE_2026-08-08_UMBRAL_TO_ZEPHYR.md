# Umbral-to-Zephyr completion wave

All 36 records in this wave used built-in ImageGen, one call per key, and a
perfect flat `#00ff00` chroma field. The untouched tool outputs are preserved
under `../generated/`; transparent masters were created with
`remove_chroma_key.py --auto-key corners --soft-matte --despill`.

Every request required one connected, standalone dark-fantasy talisman only:
no wearer, hands, neck, chain, floor, detached props/VFX, readable lettering,
or glyphs. Family B/A/S requests preserved their family's silhouette and
increased construction/material detail; named A/S requests used independent
silhouettes while retaining the manifest noun.
